## 4. 3.5 폼 유효성 검증 및 사용자 피드백 테스트

### 4.1. Post 생성 폼 검증 테스트

**테스트 케이스**: 실시간 검증 (onChange)
- ✅ 제목 입력 중 에러 메시지가 사라짐
- ✅ 내용 입력 중 에러 메시지가 사라짐
- ✅ 에러가 있는 필드에 빨간 테두리 표시

**테스트 케이스**: 제출 전 검증
- ✅ 빈 제목 제출 시 에러 메시지 표시
- ✅ 빈 내용 제출 시 에러 메시지 표시
- ✅ 제목 길이 제한 검증
- ✅ 내용 길이 제한 검증

**테스트 케이스**: 필드별 에러 메시지
- ✅ 제목 에러 메시지가 제목 필드 아래 표시됨
- ✅ 내용 에러 메시지가 내용 필드 아래 표시됨
- ✅ 에러 메시지 스타일 (빨간색, 작은 글씨)

### 4.2. Post 수정 폼 검증 테스트

**테스트 케이스**: 수정 시 검증
- ✅ 빈 제목 저장 시도 시 에러 메시지 표시
- ✅ 빈 내용 저장 시도 시 에러 메시지 표시
- ✅ 길이 제한 검증 동작 확인

### 4.3. 검증 함수 테스트

**테스트 케이스**: `validatePostTitle()`
- ✅ 빈 문자열: `{ valid: false, error: '제목을 입력해주세요.' }`
- ✅ 1-200자: `{ valid: true }`
- ✅ 200자 초과: `{ valid: false, error: '제목은 200자 이하여야 합니다.' }`

**테스트 케이스**: `validatePostContent()`
- ✅ 빈 문자열: `{ valid: false, error: '학습 내용을 입력해주세요.' }`
- ✅ 10자 미만: `{ valid: false, error: '학습 내용은 최소 10자 이상이어야 합니다.' }`
- ✅ 10-10,000자: `{ valid: true }`
- ✅ 10,000자 초과: `{ valid: false, error: '학습 내용은 10,000자 이하여야 합니다.' }`

**테스트 케이스**: `validateSubjectName()`
- ✅ 빈 문자열: `{ valid: false, error: '과목 이름을 입력해주세요.' }`
- ✅ 1-50자: `{ valid: true }`
- ✅ 50자 초과: `{ valid: false, error: '과목 이름은 50자 이하여야 합니다.' }`

**테스트 케이스**: `validateColor()`
- ✅ 유효한 hex 색상 (#FF0000): `{ valid: true }`
- ✅ 유효한 짧은 hex 색상 (#F00): `{ valid: true }`
- ✅ 잘못된 형식 (FF0000): `{ valid: false, error: '올바른 색상 코드를 입력해주세요. (예: #FF0000)' }`
- ✅ 잘못된 형식 (#GG0000): `{ valid: false }`
