## ⚠️ 주요 리스크 및 고려사항

### 기술적 리스크
1. **Google OAuth 설정** (1.2)
   - Google Cloud Console 설정 필요
   - Supabase 대시보드 설정 필요
   - 리스크: 설정 오류로 인한 지연 가능

2. **AI API 통합** (2.2)
   - AI API 선택 및 통합 필요
   - 응답 파싱 및 에러 처리 복잡
   - 리스크: API 변경 또는 실패 시 대응 필요

3. **RLS 정책 검증** (전반)
   - 모든 쿼리에서 RLS 정책 준수 확인 필요
   - 리스크: 보안 취약점 가능성

### 일정 리스크
1. **의존성 체인**
   - 1.1 → 1.2, 1.3, 1.4, 1.5 (타입 시스템)
   - 2.1 → 2.2, 2.3, 2.4, 2.5 (Posts 조회)
   - 리스크: 선행 작업 지연 시 전체 일정 지연

2. **예상 시간 변동성**
   - 복잡한 작업(1.2, 2.2)은 예상 시간의 1.5배까지 소요 가능
   - 리스크: 버퍼 시간 필요
