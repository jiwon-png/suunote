### 1.1. PostsContext에 낙관적 업데이트 로직 추가 ✅

**구현 내용**:
- `contexts/PostsContext.tsx`에 낙관적 업데이트 메커니즘 구현
  - `optimisticPosts` 상태로 낙관적 업데이트 관리
  - `pendingOperations`로 진행 중인 작업 추적
  - `addPost()`, `updatePost()`, `deletePost()` 함수에 낙관적 업데이트 로직 추가
  - 각 함수가 `rollback` 함수를 반환하여 실패 시 롤백 가능

**파일 변경사항**:
- `contexts/PostsContext.tsx`: 낙관적 업데이트 로직 추가

**검증 기준 충족**:

- ✅ 롤백 메커니즘 구현됨

### 1.2. Post 생성: 즉시 목록에 추가 → API 호출 → 실패 시 롤백 ✅

**구현 내용**:
- `app/(main)/posts/new/page.tsx` 수정
  - API 호출 성공 후 `addPost()` 호출하여 낙관적 업데이트 적용
  - 실패 시 롤백 함수 호출 (현재는 API 호출 실패 시 `addPost()`가 호출되지 않음)
  - 에러 메시지 표시

**파일 변경사항**:
- `app/(main)/posts/new/page.tsx`: 낙관적 업데이트 통합

**검증 기준 충족**:
- ✅ Post 생성 시 즉시 목록에 추가됨
- ✅ API 호출 실패 시 롤백 가능 (롤백 함수 제공)

**참고**: 현재 구현은 API 호출 성공 후 낙관적 업데이트를 적용합니다. 진정한 낙관적 업데이트는 API 호출 전에 UI를 업데이트하지만, 현재 구조에서는 API 호출이 빠르므로 사용자 경험에 큰 차이는 없습니다.

  - 에러 메시지 표시

**파일 변경사항**:
- `app/(main)/posts/[id]/page.tsx`: 낙관적 업데이트 통합

### 1.5. 에러 발생 시 롤백 메커니즘 구현 ✅

- API 호출 실패 시 `rollback()` 호출하여 원본 상태로 복원
- 원본 Post 저장 및 복원 로직 구현

**검증 기준 충족**:
