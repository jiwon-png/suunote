## 2. 로직 검증

### 2.1. 페이지네이션 로직

**서버 사이드 페이지네이션** (`getPostsPaginated`):
```typescript
const offset = (page - 1) * pageSize
query.range(offset, offset + pageSize - 1)
```
- ✅ 페이지 번호가 1부터 시작하므로 `(page - 1) * pageSize`로 offset 계산
- ✅ `range(offset, offset + pageSize - 1)`로 올바른 범위 지정
- ✅ 예: page=1, pageSize=10 → range(0, 9) (10개 항목)

**전체 개수 조회**:
```typescript
const { count, error: countError } = await supabase
  .from('posts')
  .select('*', { count: 'exact', head: true })
  .eq('user_id', userId)
```
- ✅ `head: true`로 데이터 없이 개수만 조회 (성능 최적화)
- ✅ 필터 옵션 적용하여 정확한 개수 조회

**hasMore 계산**:
```typescript
const hasMore = offset + pageSize < total
```
- ✅ 올바른 계산 (예: offset=10, pageSize=10, total=25 → hasMore=true)
