- ✅ `deleteFile()`: `deleteFiles()` 래퍼 함수
- ✅ 에러 처리 및 로깅 통합

**잠재적 이슈**:

- ⚠️ **Storage RLS 정책**: Supabase Storage 버킷에 RLS 정책을 설정해야 합니다. 현재 코드는 공개 URL을 생성하지만, 실제로는 사용자별 접근 제어가 필요할 수 있습니다.
