**주요 기능**:

- ✅ `pendingOperations`로 진행 중인 작업 추적
- ✅ `addPost()`, `updatePost()`, `deletePost()` 함수에 낙관적 업데이트 로직
- ✅ 각 함수가 `rollback` 함수 반환

**타입 안정성**:
- ✅ 타입 불일치 수정 완료 (`rollback` 함수를 반환 타입에 추가)
- ✅ 모든 함수에 TypeScript 타입 정의
- ✅ 에러 타입 명시

**로직 검증**:
- ✅ `addPost()`: 낙관적 업데이트 적용 → 롤백 함수 제공
- ✅ `updatePost()`: 원본 Post 저장 → 낙관적 업데이트 → 롤백 함수 제공
- ✅ `deletePost()`: 원본 Post 저장 → 낙관적 업데이트 → 롤백 함수 제공
- ✅ `setTimeout`을 사용하여 낙관적 상태 정리 (100ms 후 서버 데이터로 동기화)

**잠재적 이슈**:
- ⚠️ **낙관적 업데이트 타이밍**: Post 생성의 경우 API 호출 성공 후에 낙관적 업데이트를 적용하고 있습니다. 진정한 낙관적 업데이트는 API 호출 전에 UI를 업데이트해야 하지만, 현재 구조에서는 API 호출이 빠르므로 큰 문제는 아닙니다.
- ⚠️ **setTimeout 사용**: `setTimeout`을 사용하여 낙관적 상태를 정리하는 것이 안전하지 않을 수 있습니다. 컴포넌트가 언마운트되면 메모리 누수가 발생할 수 있습니다. `useEffect`와 cleanup 함수를 사용하는 것이 더 안전합니다.
